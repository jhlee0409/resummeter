# 한국 업종별 HR 이력서 검토 프로세스 리서치

> 2026-04-10 CEO 리뷰 세션에서 수집. 업종별 맞춤 프롬프트 설계의 근거.

## 1. 한국 채용 시장 2026년 현황

### 핵심 트렌드
- **인재상 1위**: 직무 전문 역량 (64.7%) → 팀워크/협업 (37.9%) → 조직 기여 의지 (28.1%) → AI/데이터 활용 역량 (24.2%)
- **채용 수요 연차**: 4-7년차 경력직이 전체 49.7% (실무 중추)
- **탈스펙 채용 확산**: 삼성/현대/SK/LG 등 대기업이 학점/어학성적 기입란 삭제, 블라인드 면접 도입
- **AI 역량 부상**: 직무 무관하게 AI 활용 업무 생산성이 평가 기준으로 자리잡음
- **"기능 → 가치"**: 채용 키워드가 "기능을 만드는 사람"에서 "가치를 만드는 사람"으로 전환

**Source**: [2026 채용 트렌드 - ZDNet Korea](https://zdnet.co.kr/view/?no=20251208160526), [2026 채용 트렌드 - 플래텀](https://platum.kr/archives/276662)

### AI 자소서 시장
- 사람인 AI 자소서 코칭: NLP 알고리즘 기반 문맥/표현/단어 분석
- 사용자 1인당 평균 6.2회 이용
- 90.4%가 플랫폼 통해 입사지원까지 전환
- 주 사용자: 20대(41.6%) + 30대(42.2%), 신입~6년 미만 저연차(68.8%)
- 시장 전망: "단순 공고 중개 → AI 기반 커리어 설계 플랫폼으로 전환 가속"

### 글로벌 시장 규모
- 이력서 최적화 서비스 시장: 2026년 $0.41B → 2035년 $0.86B (CAGR 8.5%)
- 채용 시장 전체: 2026년 $69.03B → 2031년 $98.93B (CAGR 7.47%)

## 2. IT/개발 직군

### HR 1차 검토 (서류전형)
- 기술 스택 매칭이 1차 필터
- 경력 연차 확인 (4-7년차 수요 최고)
- 포트폴리오/GitHub 링크 유무가 가산점
- "어떤 문제를 어떤 기술로 해결했는가"가 핵심

### 실무자 2차 검토 (CTO/테크리드)
- 단순 기술 나열 ✗ → "왜 그 기술을 선택했는가" 트레이드오프 설명 ✓
- 문제 발견 → 원인 분석 → 해결책 선택 과정의 논리성
- 코드 품질, 시스템 설계 능력
- 기술 문서 작성 + 시연 영상이 합격 필수 요소화

### 핵심 평가 기준
- 직무 전문 역량 64.7% (압도적 1위)
- 포트폴리오 필수: Notion, GitHub으로 프로젝트 정리
- 이력서 ≠ 나열. "내가 어떤 문제를 어떤 기술로 해결했는가"를 정량적으로 보여야 함

### 프롬프트 반영 사항
- 평가 가중치: 기술역량 40%, 경력 25%, 포트폴리오 15%, 소프트스킬 15%, 자격증 5%
- GitHub/포트폴리오 분석 강화
- 트레이드오프 설명 유도

**Source**: [합격하는 개발자 이력서 2025 - Velog](https://velog.io/@whatever/2025%EB%85%84-%ED%95%A9%EA%B2%A9%ED%95%98%EB%8A%94-%EA%B0%9C%EB%B0%9C%EC%9E%90-%EC%9D%B4%EB%A0%A5%EC%84%9C-%ED%83%AC%ED%94%8C%EB%A6%BF-Part-1), [개발자 합격 이력서 - 잡플래닛](https://www.jobplanet.co.kr/contents/news-6299)

## 3. 금융/은행 직군

### HR 검토 프로세스
- NCS 기반 블라인드 채용이 기본 (학교명, 나이, 성별 배제)
- "왜 지금 이 은행인가?"에 대한 구조적 답변 필수
- DT(디지털 전환) 전략에 대한 이해도 평가
- 금융 도메인 지식 + 디지털 역량의 교집합

### 실무자 관점 (리스크관리팀장/디지털전략팀장)
- 규제 환경에서의 혁신 경험이 차별화
- 리스크 관리 역량 (AML, KYC, 컴플라이언스)
- 고객 중심 사고 증거
- 데이터 분석 능력

### 2026년 인재상 변화
- 기존: 성실함, 책임감 중심
- 현재: 디지털 전환(DT) 시대 적합한 실무형 인재
- 핵심: "디지털 이해도 + 리스크 관리 역량 + 고객 중심 사고"

### 프롬프트 반영 사항
- 평가 가중치: 경력 30%, 소프트스킬 25%, 기술역량 20%, 자격증 15%, 포트폴리오 10%
- DT 전략/금융 이슈 연결 유도
- NCS 블라인드 채용 형식 준수

**Source**: [2026 은행권 인재상 - 링커리어](https://community.linkareer.com/employment_data/5495236), [KDB산업은행 NCS채용 - 잡코리아](https://www.jobkorea.co.kr/company/1496362/keyword)

## 4. 제조/대기업 직군 (삼성/현대/LG/SK)

### 서류전형 프로세스
- 직무적합성평가: 전공과목 이수 + 직무관련 활동 + 에세이
- 평균 서류합격률 20-30%
- 이공계: 전공 적합성으로 높은 합격률
- 비이공계(경영/전략/기획/영업): 경쟁 치열

### 탈스펙 채용
- 학점, 어학성적 기입란 삭제 확산
- 블라인드 면접 도입
- 하지만 전공 적합성은 여전히 중요

### 실무자 관점 (생산기술파트장/R&D팀장)
- 전공 깊이와 실험/프로젝트 경험
- "가치를 만드는 사람" vs "기능을 수행하는 사람" 판별
- 글로벌 역량, 문제해결/혁신 사례

### 평가 흐름
1. 서류: 기본 스펙 + 키워드 필터
2. 인적성/AI 검사: GSAT(삼성), HMAT(현대) 등
3. 실무/임원 면접: 직무 적합성, 성장 가능성, 조직문화 적합성

### 프롬프트 반영 사항
- 평가 가중치: 기술역량 30%, 경력 30%, 소프트스킬 20%, 자격증 15%, 포트폴리오 5%
- 직무적합성 강조, 전공 연관성 분석
- 에세이 형식 지원 고려

**Source**: [삼성 서류합격률 분석 - 링커리어](https://community.linkareer.com/employment_data/4065066), [대기업 탈스펙 채용 - 중기이코노미](https://www.junggi.co.kr/a.php?no=12496)

## 5. 공공기관/공기업 직군

### NCS 서류전형
- 직무능력소개서 = 경험기술서 + 경력기술서
- 블라인드 채용: 학력, 나이, 성별, 가족관계 배제
- 자기소개서가 면접 전형의 핵심 자료로 활용

### NCS 직업기초능력 10개 항목
1. 의사소통능력
2. 수리능력
3. 문제해결능력
4. 자기개발능력
5. 자원관리능력
6. 대인관계능력
7. 정보능력
8. 기술능력
9. 조직이해능력
10. 직업윤리

### 자기소개서 공통 질문
- 직업윤리
- 직장상사와의 관계 / 세대 간 격차 (의사소통)
- 차별화된 역량
- 업무 효율성 증대 방안

### 면접 평가
- 구조화된 면접: 위 10개 항목 기반
- 각 전형 단계별 선발인원 규정
- STAR 구조 기반 경험 서술이 핵심

### 프롬프트 반영 사항
- 평가 가중치: 경력 25%, 소프트스킬 25%, 자격증 20%, 기술역량 20%, 포트폴리오 10%
- NCS 10개 능력 태그 매핑
- STAR 구조 엄격 준수
- 블라인드 채용 규정 자동 체크

**Source**: [NCS 공정채용 - ncs.go.kr](https://ncs.go.kr/index.do), [공공기관 채용 - 나무위키](https://namu.wiki/w/%EA%B3%B5%EA%B3%B5%EA%B8%B0%EA%B4%80/%EC%B1%84%EC%9A%A9)

## 6. HR 실무자가 실제로 보는 것 (공통)

### 채용담당자 검토 패턴
- 이력서 평균 검토 시간: **7초**
- 상단 1/3에 핵심 성과 배치 필수
- 임팩트 중심: "무엇을 했는가" ✗ → "어떤 결과를 만들었는가" ✓
- 2026년 91%의 채용담당자가 AI 생성 이력서를 감지한 경험

### Red Flags
- 타이포, 문법 오류 → 주의력 부족
- 설명 없는 경력 공백
- 나이/결혼 등 개인정보 포함
- AI 생성 징후: "realm", "intricate", "showcasing", "pivotal", "delve" 등 특정 단어
- 과도한 볼드체, em-dash(—) 남용
- 이력서와 LinkedIn 프로필 간 톤 불일치

### 눈에 띄는 이력서
- 구체적 성과 + 숫자: "drove results" ✗ → "무엇을 만들고, 고치고, 바꿨는지" ✓
- 커리어 궤적의 논리적 일관성
- 최근 경험 우선 (3년 이내가 가장 중요)

## 7. 신입 vs 경력 차이점

### 신입
- 교내외 활동(봉사, 동아리 등) 기술이 중요
- 동아리 이름, 활동 내역, 본인 위치 등 구체적 기술
- 인턴 경험, 프로젝트가 핵심 역량 증명
- 잠재력 중심 평가

### 경력직
- 재직 기간, 회사명, 부서, 직급, 담당 업무, 수행 과제, 성취 업적을 상세 기재
- 경력 내용이 "그 사람의 모든 것"
- 성과 기반 평가

### 2026년 특수성
- "컴퓨터 활용 가능" → 무의미
- "업무 자동화를 위해 파이썬 기초를 학습하고, 엑셀 VBA를 통해 반복 작업을 30% 단축" → 구체적 기술 활용 경험

## 8. 경쟁 서비스 분석

### 사람인 AI 자소서 코칭
- 2022년 출시
- NLP 분석 알고리즘 기반
- 문맥, 표현, 단어 선택 분석 → 개선점 제안
- 강점: 대규모 사용자 베이스, 채용 공고 연동
- 약점: 범용적 (업종/직무 특화 없음), 단방향 (피드백 루프 없음)

### 잡코리아 (웍스피어)
- 새 사명 공개, "일과 관련된 모든 경험을 AI와 데이터로 재설계"
- AI 기반 커리어 설계 플랫폼 지향

### 코멘토
- AI 자기소개서 분석 서비스
- 항목별 분석 + 피드백

### 자소설닷컴
- 대기업/공기업 맞춤 채용 플랫폼
- 합격 자소서 데이터베이스

### Resummeter 차별화 포인트
1. **업종별 맞춤 분석** (사람인 등은 범용)
2. **실무자 관점 시뮬레이션** (시장에 없는 기능)
3. **코칭 적용 → 점수 실시간 반영** (피드백 루프)
4. **원클릭 파이프라인** (지원서 패키지 통합 생성)
5. **GitHub 통합** (개발자 시장 독보적)
